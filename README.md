# 一周有序

可安装到 iPhone 主屏幕的周计划与专注计时应用。静态页面，无需服务器程序、数据库或构建命令。

## GitHub Pages

将这里所有文件放在仓库根目录。Settings → Pages → Deploy from a branch → main → /(root) → Save。

等待 GitHub 给出实际发布网址，再用手机 Safari 验证能打开；访问情况取决于网络，不能保证。

Safari 分享 → 添加到主屏幕。首次联网打开，安装说明显示离线资源就绪后可离线使用。

计划与计时记录保存在当前设备，不上传到 GitHub。不要上传个人 JSON 备份到公共仓库。可在应用内导入或导出备份。

本仓库只含应用程序，不含个人计划、账号或密钥。自用网页应用，不是 App Store 安装包。
